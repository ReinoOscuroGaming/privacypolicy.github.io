# Privacy Policy – Reino Oscuro Gaming

Este repositorio contiene la **Política de Privacidad oficial** del bot de Discord de la comunidad **Reino Oscuro Gaming**.

La Privacy Policy es necesaria para cumplir con los requisitos del **Discord Developer Portal** y garantizar transparencia en el uso de datos dentro del bot.

---

## 📁 Contenido del repositorio

- `index.html`  
  Documento HTML que describe cómo el bot recopila, utiliza y protege la información de los usuarios.

- `README.md`  
  Este archivo, con información general sobre el propósito del documento.

---

## 🛡️ Sobre la Privacy Policy

La Política de Privacidad explica:

- Qué datos puede recopilar el bot
- Para qué se utilizan esos datos
- Qué datos **NO** se recopilan
- Cómo se almacenan y protegen
- Los derechos de los usuarios
- Cumplimiento con las políticas de Discord

El bot **no recopila información personal sensible** ni comparte datos con terceros.

---

## 🌐 Uso del documento

Este archivo HTML está pensado para ser:

- Publicado en **GitHub Pages**
- Enlazado desde el **Discord Developer Portal**

- Consultado públicamente por los usuarios del bot
