Política de Privacidad

Reino Oscuro Gaming
Última actualización: 2026

Reino Oscuro Gaming opera un bot de Discord diseñado para gestionar y proporcionar funcionalidades a la comunidad de Reino Oscuro Gaming.

Respetamos tu privacidad y estamos comprometidos con su protección. Esta Política de Privacidad explica qué información se recopila, cómo se utiliza y cómo se protege.

1. Información que recopilamos

El bot puede recopilar y procesar los siguientes datos:

  • ID de usuario de Discord
  • Nombre de usuario y discriminador de Discord
  • ID de roles de Discord
  • Contenido de mensajes únicamente cuando sea necesario para la ejecución de comandos
  • Datos de interacción (botones, comandos slash, registros de uso)

El bot NO recopila:

  • Direcciones de correo electrónico
  • Direcciones IP
  • Nombres reales
  • Información de pago o financiera

2. Uso de la información

Los datos recopilados se utilizan exclusivamente para:

  • Ejecutar comandos del bot
  • Gestionar funcionalidades del servidor
  • Registrar acciones administrativas
  • Moderación y gestión del servidor
  • Mejorar la estabilidad y el rendimiento del bot

Los datos nunca se venden, comparten ni transfieren a terceros.

3. Almacenamiento de datos

  • Los registros se almacenan de forma local o en servidores privados controlados por Reino Oscuro Gaming.
  • Los datos se conservan únicamente el tiempo necesario para fines operativos.
  • No se realiza almacenamiento innecesario a largo plazo.

4. Derechos del usuario

Tienes derecho a:

  • Solicitar la eliminación de tus datos registrados
  • Consultar qué información relacionada con tu cuenta se almacena
  • Dejar de usar el bot en cualquier momento abandonando el servidor de Discord

Para cualquier solicitud, contacta con un administrador del servidor.

5. Servicios de terceros

El bot opera exclusivamente dentro de Discord y cumple con:

  • Términos de Servicio de Discord
  • Política de Desarrolladores de Discord

No se utilizan servicios externos de analítica ni seguimiento.

6. Seguridad

Se aplican medidas técnicas y administrativas razonables para proteger los datos frente a accesos no autorizados o usos indebidos.

7. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando sea necesario. Los cambios se reflejarán con una fecha de revisión actualizada.

8. Contacto

Para cualquier duda o consulta relacionada con esta Política de Privacidad, contacta con los administradores de Reino Oscuro Gaming a través del servidor oficial de Discord.
